# HM20260918 — Todo List

A single-file, zero-dependency **Todo List** web app.

## Features
- Add / delete / toggle (done · not-done) items
- Persisted in browser `localStorage`
- Modern dark UI, responsive, accessible

Open `index.html` in any browser — no build, no server.

## Live (GitHub Pages)
Auto-built and deployed on push to `main` via the GitHub Actions workflow in
`.github/workflows/deploy-pages.yml`.
